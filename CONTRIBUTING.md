# Contributing to Saydaliati

Thank you for your interest in improving Saydaliati!

## How to Contribute

1. **Fork the Repository** and clone your fork locally.
2. **Create a Feature Branch**: `git checkout -b feature/your-feature-name`.
3. **Run Code Formatting & Analysis**:
   ```bash
   flutter format .
   flutter analyze
   flutter test
   ```
4. **Commit Your Changes** with clear conventional commit messages (`feat:`, `fix:`, `docs:`).
5. **Open a Pull Request** describing your changes and link any related issues.

## Reporting Bugs & Suggesting Features

Please open an issue on GitHub describing the behavior you experienced and steps to reproduce.
